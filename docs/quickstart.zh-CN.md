# MoonCell 1.0 使用说明

双击 `MoonCell.html`，或者打开源码目录中的 `dist/MoonCell.html`。无需安装 Excel，不需要联网。

## 先体验错误引用

打开后默认加载合成报价表。右侧选择 F7，查看它为何与前后四个公式不同。点击“预览候选对结果的影响”，可看到按候选修改后，明细从 4800 变成 5400，含税总计从 57240 变成 57876。这些是合成样例的实际重算结果，不是现实业务发现。

## 再试一张真实表格

点击“打开我的工作簿”，选择自己允许分析的 XLSX。待核查项会列出当前公式、四个同类邻居和候选。没有发现异常不等于表格正确。请展开“分析范围与文件提示”，查看未支持内容。

## 核对两版

先打开新版，再选择旧版。只有在两版工作表名称和行列位置对应时才勾选确认；本版不会对齐插入、删除或移动的行列。点击“检查公式变化”。

## 保留审核结果

可标记“确认是问题”或“合理例外”，并填写最多 2000 字的备注。

1. 点击左侧“保存审核进度”，下载 `.mooncell.json` 会话文件。这包含全部导入单元格、可选旧版以及判断和备注。
2. 下次打开 MoonCell，点击“恢复审核进度”选择该文件。工具会验证完整性并重新运行分析，证据匹配后恢复判断。损坏或不兼容的文件不会替换当前工作簿。
3. 点击右上方“导出可读报告”，把生成的 HTML 交给同事直接阅读或用浏览器打印；“导出 JSON 记录”供其他工具读取。这两种报告均不能恢复审核进度。

本工具不自动持久保存。关闭前请确认会话已下载；打开其他工作簿会开始新的审核。会话和报告均包含业务数据，按原文件的敏感程度保管。原始工作簿不会被改写。SHA-256 校验不能证明来源真实性，收到他人的判断仍需业务复核。

## 定位与筛选

在定位框输入 `AA120` 可跳至对应窗口；使用四个方向按钮移动行列。右侧按“待核查／确认问题／合理例外”筛选，或搜索地址、公式与备注。列表最多展示前 200 项，报告仍包含全部发现。

导入和重算在后台进行；点击“取消分析”可停止。30 秒仍未完成会自动停止，可缩小表格后重试。

## 当前限制

1.0 是首个正式发布版，算法仍是保守的邻域结构基线。暂无真实用户效果评估，不应替代业务复核。复杂数组、动态或外部引用等不能完整分析。具体范围见 README。
