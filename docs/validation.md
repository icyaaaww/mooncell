# 验证记录

日期：2026-10-19。环境：Windows、MoonBit moon 0.1.20261012、Node.js 24。

核心回归覆盖引用平移、绝对/混合引用、带引号跨表引用、公式样式一致性、边界不自动推断、合理折扣例外、明确的版本变化、重新计算、缓存不可信、循环/零除/未知函数失败和输入预算。JS、Wasm-GC 分别运行同一套测试。

XLSX 样例由独立的 Python/openpyxl 生成，包含中文实体、公式和数值。期望修复前后结果用独立 Python 算术计算，未调用 MoonBit 解析器。额外适配测试覆盖共享公式、共享富文本、数组公式提示、DTD 拒绝与 ZIP 解压前限制。

浏览器测试使用 Chromium 和 Firefox，覆盖文件导入、证据及预览、同地址比较确认、例外判断、审查下载、错误导入不覆盖现有数据、窄屏以及文本安全渲染。已发现并修复单文件打包时 `$` 替换串破坏脚本的问题。

## 明确缺少的证据

- 所有内置业务案例均为合成数据，没有真实用户采用记录。
- 未完成 ExceLint 对照或公开标注真实表格评测。
- 不报告准确率、召回率或性能优势；少量合成回归用例不能支持这些结论。
- 合理折扣例外会触发规则。界面允许人工记录例外，不声称算法已自动辨别。
- 浏览器检查不能证明完整 OOXML 兼容；ZIP/XML 适配器不是安全认证工具。
