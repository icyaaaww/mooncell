# 第一轮真实试用任务

状态：试用计划，尚未邀请或获得真实试用结果。不要把下面的目标写成已完成的采用证据。

寻找维护报价单、预算表或实验计算表的 3 位使用者。在得到文件所有者允许后，仅使用必要且脱敏的工作簿。工具在本机运行。

1. 先记录用户如何人工检查一份表格，以及预计耗时。
2. 导入其本人熟悉的表格，核查前 5 个候选（若不足则全部）。记录真实问题、合理例外、无法判断，保留判断依据。
3. 使用真实旧版/新版，确认行列位置一致后，对比哪些变化有价值；行列发生移动的文件应记录为首版不适用。
4. 选择一个受支持的候选，用 Excel 或 LibreOffice 独立核对修改前后的数值。不将工具自己的重算结果当作独立验证。
5. 记录导入失败、未支持公式、误报、漏报和实际使用时间。

建议表单字段：匿名参与者编号、文件类型、公式数、候选数、前五候选分类、真实问题描述、验证工具及结果、人工/工具流程用时、使用者是否愿意继续使用及原因。

后续申报只引用获得许可、可核对的实际结果。没有用户反馈时明确写未验证。
