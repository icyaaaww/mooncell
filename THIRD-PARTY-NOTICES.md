# Third-party components

- MoonBit standard library and generated runtime: Apache-2.0. See `third-party/moonbit-core-LICENSE` and `third-party/moonbit-core-NOTICE`.
- `fflate` 0.8.3: MIT. ZIP adapter dependency. See `third-party/fflate-LICENSE`.
- `fast-xml-parser` 5.11.2: MIT. XML adapter dependency. See `third-party/fast-xml-parser-LICENSE`.
- Its transitive dependencies are pinned in `package-lock.json`; corresponding runtime licenses are included in `third-party/`.
- esbuild and Playwright are build/test dependencies, not part of the reusable MoonBit library.

ExceLint is a conceptual reference and a planned comparison baseline. No ExceLint source code or datasets have been copied into this version. See `docs/provenance.md`.
